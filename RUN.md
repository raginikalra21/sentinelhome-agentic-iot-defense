# SentinelHome — Run Guide 🏠🔐

This guide explains how to run **SentinelHome**, an edge-based, agentic IoT security system.

⚠️ SentinelHome is **not a website**.  
It must be run **locally inside a network** and some components require `sudo`.

---

## ✅ Prerequisites

- Python 3.9+
- macOS or Linux (recommended)
- Git
- Terminal access

---

## 📥 Step 1 — Clone the Repository

```bash
git clone https://github.com/<your-username>/sentinelhome-agentic-iot-defense.git
cd sentinelhome-agentic-iot-defense
